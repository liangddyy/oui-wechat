# 验证范围

## 已验证

- Python 3.14 本机运行及 Open WebUI 0.12.0 的真实认证和 WebSocket 身份确认。
- 真实微信扫码、收发回复及 Open WebUI 中的用户消息与 AI 回复持久化。
- 两个独立客户端接续同一会话，适配器重新读取服务端最新分支。
- 从网页记忆接口写入后，在新会话读取；模型调用内置工具后，后台可查到新增记忆。
- 新增的虚构测试记忆在验证后定向清理，不删除原有业务记录。
- 管理 API 的管理员认证、会话撤销、请求来源校验、设置校验、令牌脱敏。
- 两个模拟微信用户独立绑定与移除、按账号过滤模型、绑定变更时清理旧会话焦点。
- 浏览器扫码状态与数字配对码回调。外部服务使用测试替身，避免自动化测试真实授权账号。
- 浏览器回归覆盖首次设密、设置持久化、改密与退出、账号绑定、模型切换、
  配对码、移除确认，以及桌面、390px 和 320px 布局。页面脚本与图标均使用本地资源。
- 已在飞牛 x86_64、Docker 28.5.2、Compose 2.40.3 上完成镜像构建和健康启动，
  验证非 root 用户、只读根文件系统、数据目录权限、JWT、WebSocket 和重启后状态保留。
- Docker 构建会规范化应用代码的读取权限；持久数据目录不进入构建上下文。
- 用户入口使用模拟 Open WebUI 验证登录、停用/过期/撤销身份、角色隔离和后端变更后的会话失效。
- 普通用户账号列表、统计、模型操作及二维码查看/配对码/取消均校验归属；管理员可管理全部连接。
- 扫码自动绑定当前用户，重复扫描其他用户的微信会在落库前拒绝；
  解绑、移除和服务重启后保留归属，管理员可重新分配连接。
- 管理员改绑与微信入站同时发生时，入站等待改绑完成，再读取当前绑定；
  关闭并重新开启用户入口不会恢复旧登录会话或待完成的扫码。
- 账号/IP/全站登录预算、HTTP 429、并发上限、限流计数重启保留与过期，
  以及可信反代链与伪造转发头的处理均有离线回归。
- 普通用户浏览器回归使用真实 Web API 和外部服务替身，覆盖登录、空状态、扫码、
  自动绑定、解绑后绑定自己、第二用户隔离、管理员查看全部、320px/390px 布局与重试倒计时。
- 飞牛新版实际验证用户/管理员入口、320px 登录页、匿名 API 拒绝访问、旧绑定归属迁移，
  以及保存的 JWT 对应真实 Open WebUI 身份；升级前后微信授权、绑定和焦点表内容一致。
- 图片离线回归覆盖先图后文、文字立即入队、多图及队列边界、两用户并发隔离、
  固定超时、失败重试、重启恢复、提交状态去重、视觉能力检查及临时图片历史。
- 媒体协议回归覆盖密钥编码、AES/PKCS7、图片验证和大小限制、CDN 地址校验、
  OpenWebUI 上传鉴权、禁止跳转、原生微信图片消息结构及回复图片去重。
- 生图等待回归使用虚拟时间覆盖静默 7 分钟成功、30 分钟总时限、普通文字保留原空闲超时、
  工具事件延长等待；队列回归覆盖生图预检/生成期间拒收文字、图片和会话命令，
  `/stop` 可用、完成后恢复接收、非生图请求仍可排队及按用户隔离。
- 真实 `WebAdapter` 工作线程与 `ImageChatRunner` 的集成回归覆盖媒体开启时的纯文字、
  先图后文和生图拒收回调；仅模拟网络边界，不替换聊天执行类，防止构造参数不兼容漏测。
- 飞牛候选镜像使用生成的纯色测试图实测微信 CDN 加密上传、OpenWebUI 图片上传下载、
  同一条用户消息的图片附件持久化、真实模型识图及历史图片追问；测试聊天和文件已定向清理。
- 图片版已在飞牛健康启动，原有三个微信授权、绑定和会话焦点与升级前备份一致，
  三条微信轮询恢复，媒体目录与数据库权限分别为 0700、0600。

完整离线验证：

```sh
uv run python scripts/validate.py --label local
```

浏览器回归先在一个终端运行隔离测试服务，再在另一个终端运行测试：

```sh
uv run python tests/serve_browser.py
npm ci
npm run test:browser
```

测试服务仅监听本机 8790，使用临时目录与虚构账号，不能用于实际微信或后端验证。

该命令执行附带适配器的 7 组测试、Socket.IO 与双端续聊回归、Web 管理接口测试和静态检查。
结果保存在忽略提交的 `reports/`，不会将实际用户、聊天或实例地址发布到仓库。

## 尚需验收

- 微信真实图片下载、识图、网页图片显示与继续追问、AI 回图，
  以及两个真实微信用户的图片隔离，仍需手机端验收。
- 迁移后由手机发送新消息的最终收发确认，以及不同部署方式的数据卷验收。

不能将模拟多用户测试、静态 Compose 检查或模型声称“已记住”视为这些项目已通过。
