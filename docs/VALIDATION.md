# 验证说明

## 自动化测试

安装开发依赖并运行离线测试：

```sh
uv sync --frozen
uv run python scripts/validate.py --label local
uv run ruff check oui_wechat tests scripts validation
```

测试使用临时数据和虚构账号，不需要微信授权或 Open WebUI 凭据，不连接正式服务。
报告保存在 `reports/`，不提交到 Git。

覆盖范围：

- 附带适配器的能力推导、协议字段、文字渲染、会话队列、临时会话和输入状态。
- Socket.IO 身份与会话分支接续、网页仍在生成时拒绝接续。
- 管理员认证、Open WebUI 用户入口、账号归属、跨用户访问拒绝、会话撤销。
- 登录尝试限制、HTTP 429、重启后计数保留、可信反向代理及转发头校验。
- 图片先图后文、多图批次、超时、失败重试、重启恢复、消息去重和用户隔离。
- AES 密钥编码与加解密、媒体大小和像素限制、CDN 地址校验及回复图片去重。
- 生图等待上限、生成期间拒收新消息、完成后恢复接收和 `/stop`。
- 使用真实聊天执行类的工作线程集成测试，覆盖文字、图文与生图状态回调；网络边界使用测试替身。

浏览器回归需要在一个终端启动隔离测试服务，再在另一个终端运行浏览器测试：

```sh
uv run python tests/serve_browser.py
```

```sh
npm ci
npx playwright install chromium --only-shell
npm run test:browser
```

测试服务仅监听本机 `8790`，使用临时目录和外部接口替身。
浏览器测试覆盖登录、空状态、扫码与配对码、绑定、模型切换、设置、确认弹窗和移动端布局。
不要把浏览器测试指向已有账号的正式管理服务。

## 实例验收

已测试的 Open WebUI 版本为 **0.12.0**。接口和微信客户端行为可能随版本变化，
部署到新环境或升级后应按以下流程验收：

1. 使用测试账号在网页完成微信授权和绑定，确认普通用户只能访问自己的连接。
2. 从微信发送文字，在 Open WebUI 网页核对用户消息和 AI 回复；从网页续聊后再回到微信追问。
3. 先发送图片再发送问题，核对识图结果、网页附件显示、后续追问和 AI 图片回传。
4. 使用两个独立账号交错发送图文，确认会话、暂存图片和回复不会串到另一用户。
5. 检查所用模型的记忆和工具权限；生图过程中发送额外消息，确认拒收并在完成后恢复。
6. 备份后重启容器，确认微信授权、绑定和管理密码保留，管理服务健康且账号连接恢复。

Docker 健康检查只确认管理服务存活，不能替代真实消息收发验收。
模拟测试不能替代手机端验证；支持范围见根目录 README。

开发探针仅用于明确指定的测试实例。报告、截图、日志、数据库和媒体目录可能包含私有信息，
应保存在被忽略的目录内，不能作为公开发布附件上传。
